# مقدمة في برمجة الويب بلغة PHP4

## نظرة عامة

يحتوي هذا المستودع على **مواد تعليمية مخصصة لبرمجة الويب باستخدام PHP4**.
وهو عبارة عن وثيقة تعليمية مصممة لدعم التدريس ولا تشكل دورة شاملة.

تتيح هذه الوثيقة للطلاب اكتشاف أساسيات برمجة الويب بلغة PHP وتوفر موردًا لممارساتهم وتجاربهم.

## أصل الوثيقة

تستمد هذه المواد مباشرة من دورة **"مقدمة في برمجة الويب بلغة Java"**.
تم الحفاظ على الهيكل التعليمي، ولكن تم **تكييف الأمثلة والحلول مع لغة PHP**.

وبالتالي، يمكن للقارئ الملم بـ **Java و PHP** مقارنة:
* حل Java
* حل PHP

**لنفس مشكلة البرمجة على الويب**.

## أهداف التعلم

يهدف هذا المورد إلى:
* تقديم أساسيات البرمجة على الويب من جانب الخادم
* عرض أمثلة ملموسة على كود PHP
* العمل كأساس عملي للطلاب
* إتاحة مقارنة تعليمية بين Java و PHP
